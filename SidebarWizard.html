What is an E-sign type?
A signing workflow for a group of rows — e.g. MOU, Invoice, PO. One sheet can hold many types.

Buttons on each type
▶️ Run — check the rows now and create signing jobs.
✏️ Edit — change its configuration.
⏸ Pause — stop it from running automatically (resume later).
📋 Copy — duplicate the type (e.g. for another sheet/rows).
📜 Audit — view the audit events recorded for this E-sign.
🗑️ Delete — remove the type. Links already written stay intact.

Scheduling
Each E-sign has its own schedule, set once in the wizard (Step 6). Pause/Resume switches it on and off. The installable time trigger is created once, automatically.

How a signature happens
1. A row is marked Signing Required = Yes (and has a PDF).
2. DocuPDF creates the job and writes one-time sign links into the row.
3. Signers open their link, draw/type a signature; when all parties sign, the _SIGNED.pdf is saved with an audit stamp.
For details see the SETUP.md guide or the E-sign wizard's per-step ? help.
